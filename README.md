# 架空ECサイトの売上向上を目的としたデータ分析・マーケティング施策提案

## 概要

架空ECデータ「TheLook eCommerce」を使用し、SQLによるデータ抽出・集計、Pythonによる品質確認・分析、Tableauによる可視化を行いました。

売上の変動を注文数と平均注文単価に分解し、商品カテゴリ・顧客の購入回数を分析して、売上・利益向上に向けた施策と検証方法を提案します。

※学習用の架空データを用いた分析です。施策は未実施であり、実際の売上改善実績を示すものではありません。

## データと集計条件

データソース：
- `bigquery-public-data.thelook_ecommerce.order_items`
- `bigquery-public-data.thelook_ecommerce.products`

商品IDをキーにLEFT JOINし、注文明細にカテゴリと商品原価を付与しました。

| 項目 | 定義 |
|---|---|
| 分析期間 | 2025年9月1日以上、2026年9月1日未満 |
| 日付基準 | 注文明細の作成日時（UTC） |
| 売上の対象 | ステータスがCompleteの明細 |
| 売上 | 対象明細の販売価格合計 |
| 注文数 | 対象明細に含まれる注文IDのユニーク数 |
| 平均注文単価 | 売上 ÷ 注文数 |
| 参考粗利 | 販売価格 − 商品原価 |
| 金額の単位 | 元データの値を使用。通貨換算なし |

参考粗利には広告費・送料・その他の経費を含みません。
月別注文数は各月内で重複を除き、全期間の注文数は全期間で重複を除いて計算します。

## データ品質の確認

- 抽出データ：64,400明細、9列
- 全カラムの欠損数：0
- 明細IDの重複数：0
- 日時・金額の型変換後の欠損数：0
- 分析期間外の明細数：0
- 販売価格・商品原価のマイナス件数：0
- 分析対象のComplete明細：16,301件

SQL集計値とPython集計値を照合し、売上は小数第2位で一致しました。参考粗利には0.01の差があり、カテゴリ別集計値を丸めてから合算する場合と、明細から全体を合算して丸める場合の差として整理しています。

## 主要な分析結果

### 全期間の実績

| 指標 | 値 |
|---|---:|
| 売上 | 963,310.83 |
| 参考粗利 | 499,877.32 |
| 注文数 | 11,196 |
| 購入顧客数 | 10,419 |

### 1. 注文数の増加だけでは売上は伸びない

2026年6月は前月比で注文数が5.17%増加した一方、平均注文単価が4.94%低下し、売上は0.03%減少しました。

平均注文単価を分解すると、1注文あたりの商品点数が1.68%、商品1点あたりの平均販売価格が3.32%低下していました。

### 2. 7月の売上増加には一部カテゴリが大きく寄与

2026年7月は前月比で売上が31.87%増加しました。注文数は18.47%、平均注文単価は11.31%増加しました。

Outerwear & Coats、Suits & Sport Coats、Accessoriesの3カテゴリが、全体の売上増加額の約39.1%を占めました。

### 3. 複数回購入した顧客の売上構成比

期間内に2回以上購入した顧客は734人で、顧客数の7.04%、売上の12.90%を占めました。

これは期間内の購入回数による区分であり、生涯の購入回数や新規・既存顧客の区分ではありません。顧客によって観察期間も異なるため、この割合だけでリピート率の良し悪しは判断しません。

## マーケティング施策の提案

| 施策 | 分析とのつながり | 実施案 |
|---|---|---|
| 関連商品の提案 | 6月に1注文あたりの商品点数が低下 | 商品詳細・カートで関連商品を表示し、追加購入を促す |
| 成長カテゴリの露出検証 | 3カテゴリが7月の売上増加額の約39.1%を占める | 在庫・商品別利益を確認し、トップページの特集枠を試す |
| 購入後のフォロー | 期間内の複数回購入顧客が売上の12.90%を占める | 配信同意のある購入者へ関連商品を案内する |

まずは、購入点数の低下に対応する「関連商品の提案」を優先候補とします。実装工数と対象ユーザー数を確認したうえで、実施の優先順位を決めます。

### 効果の検証方法

- 対象者を無作為に施策あり・なしへ分け、A/Bテストを行う。
- 対象者1人あたりの参考粗利を主指標とし、売上・購入率・平均注文単価も確認する。
- 購入後のフォローでは、両群に同じ観察期間を設け、30日以内の再購入率を比較する。
- 返品率や配信解除率など、悪化していないか確認する指標も設定する。
- テスト前に必要な対象者数、実施期間、成功基準を決める。
- 参考粗利の増分から追加費用を差し引き、採算を判断する。

## 分析の限界と今後の課題

- 架空データの傾向を、実在するEC事業へそのまま適用することはできません。
- 売上変動の原因が広告・季節性・価格変更のどれかは、今回の分析だけでは特定できません。
- 商品1点あたりの平均販売価格は、購入される商品の構成によっても変動します。
- 今回抽出したデータにはアクセス数・広告費・在庫情報を含まないため、購入率や広告の採算は未分析です。
- 今後は商品別の価格・販売構成の分析、初回購入月別に観察期間をそろえた再購入分析を行います。

## 再実行方法

1. BigQueryで `sql/01_extract_order_items.sql` を実行する。
2. 結果を `order_items_detail.csv` として保存する。
3. `notebooks/ec_sales_analysis.ipynb` をGoogle Colabで開く。
4. 最初のセルでCSVをアップロードし、上から順に実行する。
5. 最後のセルで出力される `tableau_sales_detail.csv` をTableauに読み込む。

月別・カテゴリ別のSQLは、それぞれBigQueryで実行できます。

公開データセットは更新されるため、再取得時の件数や集計結果は本READMEの値と異なる場合があります。記載した結果は、今回の分析に使用したCSVに基づきます。
