# 架空ECサイトの売上分析と改善案

## 概要

データ分析の学習として、架空のECデータ「TheLook eCommerce」を使い、売上の変化や売れている商品カテゴリ、顧客の購入回数を調べました。

SQLでデータを取り出し、Pythonで集計・分析を行い、Tableauでグラフにまとめました。分析結果をもとに、売上を伸ばすための改善案も考えました。

## 分析したデータ

- 使用データ：TheLook eCommerceの注文明細と商品データ
- 分析期間：2025年9月1日〜2026年8月31日
- 売上の集計対象：注文ステータスが「Complete」の明細
- 対象明細数：16,301件

分析前に、データの抜けや明細IDの重複がないことを確認しました。また、SQLとPythonで計算した売上が一致することも確認しました。

## 分析結果

### 全期間の集計

| 項目 | 結果 |
|---|---:|
| 売上 | 963,310.83 |
| 参考粗利（売上から商品原価を引いた金額） | 499,877.32 |
| 注文数 | 11,196件 |
| 購入した顧客数 | 10,419人 |

※金額は元データの値を使用しており、日本円への換算はしていません。参考粗利には広告費や送料などを含みません。

### 1. 注文が増えても、売上が伸びない月があった

2026年6月は、5月と比べて注文数が約5.2%増えました。しかし、1回の注文で使われる金額が約4.9%下がったため、売上はほぼ変わりませんでした。

詳しく調べると、1回の注文で買われる商品数と、商品1点あたりの平均販売価格の両方が下がっていました。

このことから、注文数だけでなく、「1回の注文で何点、いくら購入されているか」も確認する必要があると考えました。

### 2. 7月の売上増加に大きく貢献したカテゴリがあった

2026年7月は、6月と比べて売上が約31.9%増えました。注文数と、1回の注文で使われる金額の両方が増えていました。

特に、次の3カテゴリが、売上が増えた金額の約39.1%を占めていました。

- Outerwear & Coats（アウター・コート）
- Suits & Sport Coats（スーツ・ジャケット）
- Accessories（アクセサリー）

これらの商品を見てもらう機会を増やすことで、さらに売上につながるか確かめたいと考えました。ただし、7月に伸びた理由は、今回の分析だけではわかりません。

### 3. 期間内に2回以上購入した顧客は約7%だった

分析期間内に2回以上購入した顧客は734人で、購入した顧客全体の約7.0%でした。この顧客たちの売上は、全体の約12.9%を占めていました。

購入後にも商品を案内することで、再び購入してもらうきっかけを作れるのではないかと考えました。

ただし、今回の期間より前の購入履歴は確認していません。そのため、この結果だけで「リピートが少ない」とは判断できません。

## 売上を伸ばすための改善案

| 改善案 | 考えた理由 | 具体的な内容 |
|---|---|---|
| 関連商品を表示する | 6月は1回の注文で買われる商品数が減っていたため | 商品ページやカートに、一緒に使える商品を表示する |
| 売上が伸びたカテゴリを紹介する | 7月の売上増加に大きく貢献していたため | 在庫や利益を確認したうえで、トップページに特集を掲載する |
| 購入後に商品を案内する | 再び購入してもらうきっかけを作るため | メール配信に同意した購入者に、関連商品を紹介する |
